# Continuidade e preservação

Instrução do proprietário em 24/10/2026: enviar ao GitHub toda atualização atual
e futura para evitar perdas. Ao concluir uma atualização, criar commits e fazer
push de sua branch, incluindo código, documentação, resultados e artefatos
necessários para reprodução. Preservar também os pesos treinados; para arquivos
acima dos limites do GitHub, usar armazenamento apropriado autorizado e registrar
localização e hashes. Se o envio falhar, informar explicitamente o que ficou local.
Nunca versionar credenciais, segredos ou dados privados. Merge não está incluído
nesta instrução. Evitar alterações destrutivas no histórico.

Manter o Transformer linguístico próprio, sem substituir por pesos pré-treinados
ou APIs externas. Identificar dados sintéticos e separar ensaios de memorização de
avaliações de generalização. Voice Core permanece pausado.
