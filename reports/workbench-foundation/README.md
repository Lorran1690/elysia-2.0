# Bancada e registro de habilidades

Primeira entrega do memorando no aplicativo: inspeção estática PE/ELF/ZIP/APK,
estrutura Python com grafo sintático navegável, revisão de texto reversível,
projeto exportável, anotação no Vault e catálogo de 21 áreas com limites reais.

O fluxo é inspirado no Eleven 0.1.13 (Apache-2.0); implementação própria.
Não é integração dos agentes ACP/MCP ou decompiladores do Eleven.
Não conclui as metas de longo prazo do memorando. Os pesos neurais não mudaram.

194 testes Python aprovados, 9 ignorados, testes Node de mídia aprovados.
Fluxo do navegador fonte aprovado, sem erros JavaScript ou requisições externas.
O workflow desktop exige repetir a bancada no EXE real e preserva o relatório
workbench-browser.json antes da publicação. O catálogo não é um teste neural.
