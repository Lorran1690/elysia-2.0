# Apresentação da Elysia

Vídeo MP4 H.264 de 60 segundos, 1280×720, 30 fps e 1.800 quadros decodificados pelo ffprobe. Seis cenas sobre identidade, pesquisa neural, conhecimento, mídia, código e evolução. Sem áudio ou narração.

Renderizado quadro a quadro com scripts/render-presentation.py; o caminho MP4 exige ffmpeg/Playwright e não está embutido no EXE. O aplicativo recebeu o mesmo roteiro em um preset de 60 segundos/720p para exportação WebM em tempo real. Essa captura pode perder quadros conforme o computador.

Testes: fluxo completo de mídia no Chromium aprovado (inclui preset, exportação, cancelamento, projeto, pasta simulada e isolamento HTML); testes Node aprovados; 6 testes Python de integridade web e ferramentas aprovados. Storyboard inspecionado pelo Codex. Sem revisão humana independente.

Vídeo privado no Google Drive conforme preferência do proprietário; identificadores de pasta e arquivo não publicados no Git. Pesos neurais inalterados; Voice Core pausado.
